# October 2026 Patch Tuesday Briefing

*Release date: October 13, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The October 2026 security update spans **1,760 entries** in Microsoft's CVRF document
(including bundled open-source and third-party components Microsoft redistributes). Of those:

- **174 Critical** and **1,432 Important** severity
- **2 publicly disclosed** before the release
- **1 on the CISA KEV catalog**: the Windows Shell Security Feature Bypass [CVE-2026-96951](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96951), confirmed exploited, federal remediation due **October 16, 2026** — patch this first if you do nothing else
- Impact mix: Elevation of Privilege (677) leads, followed by Remote Code Execution (317) and Information Disclosure (253)

## What to patch first

1. **Windows Shell Security Feature Bypass** — [CVE-2026-96951](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96951)
   is the only entry on the **CISA KEV** catalog this month, meaning exploitation is
   confirmed in the wild. CVSS 8.8, command injection via a crafted file. Fixed by the
   October cumulative updates (KB5126646–KB5127648 family) — ship it today.
2. **Active Directory Domain Services RCE** — [CVE-2026-70229](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-70229)
   (CVSS 8.1 Critical, unauthenticated network RCE) carries Microsoft's **"Exploitation
   More Likely"** assessment. Domain controllers deserve an early maintenance window.
3. **The network-service RCE trio** — Windows DHCP Server
   [CVE-2026-96934](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-96934),
   Microsoft QUIC [CVE-2026-100219](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-100219)
   and [CVE-2026-105016](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-105016),
   and Message Queuing (MSMQ) [CVE-2026-100202](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-100202)
   are all **CVSS 9.8 Critical, unauthenticated RCEs** in services that are easy to
   forget are even running. Any server acting as a DHCP server, terminating QUIC/HTTP3,
   or with MSMQ enabled is in scope — all fixed by the same October cumulatives.
4. **Microsoft Exchange Server RCE** — [CVE-2026-70571](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-70571)
   (CVSS 8.1 Critical, stack buffer overflow), also flagged **"Exploitation More
   Likely."** Exchange has a well-earned reputation as a priority target — patch on-prem
   servers this cycle.
5. **Raw Image Extension RCE** — [CVE-2026-21413](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-21413),
   CVSS 9.8 Critical, heap overflow triggered by opening a crafted image. Client-side,
   but zero user interaction once the file is opened — Microsoft Store auto-updates this
   on most machines, but verify fleet-managed devices picked it up.

The two publicly disclosed items — .NET Framework Security Feature Bypass
[CVE-2026-108398](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-108398)
and MessagePack-CSharp Denial of Service
[CVE-2026-92707](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-92707) —
are Important/Moderate severity with "Exploitation Less Likely" assessments: patch on
the normal cycle, but assume proof-of-concept details are circulating.
