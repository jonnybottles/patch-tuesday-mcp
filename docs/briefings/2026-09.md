# September 2026 Patch Tuesday Briefing

*Release date: September 8, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The September 2026 security update spans **1,185 entries** in Microsoft's CVRF document
(including Chromium/Edge and open-source components Microsoft redistributes). Of those:

- **119 Critical** and **913 Important** severity
- **0 publicly disclosed** before the release — no zero-days by disclosure this month
- **2 on the CISA KEV catalog**, both confirmed exploited in the wild: [CVE-2026-81963](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-81963)
  (Windows Update Stack EoP) and [CVE-2026-85880](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-85880)
  (Windows ALPC EoP), federal remediation due **September 22, 2026**
- Impact mix: Elevation of Privilege (438) leads, followed by Remote Code Execution (258) and Information Disclosure (173)

## What to patch first

1. **The two KEV-listed Windows privilege-escalation bugs** — [CVE-2026-81963](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-81963)
   (Windows Update Stack) and [CVE-2026-85880](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-85880)
   (Advanced Local Procedure Call) are both **confirmed exploited in the wild**, CVSS 7.8.
   Local EoP bugs like these are exactly what attackers chain onto an initial foothold —
   treat them like a Critical RCE. Federal remediation is due **September 22**.
2. **Windows DNS Server RCE** — [CVE-2026-69730](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69730)
   is a **CVSS 9.8 Critical**, unauthenticated, network-reachable use-after-free
   (CWE-416) that Microsoft's own exploitability index rates **"Exploitation More Likely"**
   — no EPSS score has been published for it yet (it's one day old), so this one won't
   show up near the top of an EPSS-sorted list even though it's arguably the most
   dangerous bug this month. Any domain controller running the DNS Server role is in scope.
3. **Windows Kerberos RCE** — [CVE-2026-69676](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69676),
   Critical, CVSS 8.8, also tagged "Exploitation More Likely." Kerberos means domain
   controllers again — pair this patch window with the DNS Server fix above.
4. **Remote Desktop Services RCE** — [CVE-2026-69525](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69525),
   CVSS **9.8**, "Exploitation More Likely." Anywhere RDS or an RD Gateway is exposed
   deserves this month's first maintenance window.
5. **Windows Schannel RCE** — [CVE-2026-72940](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-72940),
   Critical, CVSS 8.8, "Exploitation More Likely." Schannel underlies TLS on Windows —
   broad exposure across anything terminating TLS on the OS stack.

No entries were publicly disclosed ahead of the release this month, so there's no
"assume PoC code is circulating" category this time — but the five items above, all
Microsoft-flagged as more likely to be exploited, deserve the same urgency EPSS would
normally signal once it catches up.

## Reproduce this briefing

This page is the output of a few tool calls against the free, keyless MSRC API:

```
msrc_search(month="2026-Sep", include_stats=True, format="markdown")
msrc_search(month="2026-Sep", exploitation_likely=True)
```

The second call is what surfaces the DNS Server, Kerberos, RDS, and Schannel RCEs above
that EPSS hasn't caught up to yet.

Run it from any MCP client via [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)
(`uvx patch-tuesday-mcp`), or try the [hosted endpoint](https://github.com/jonnybottles/patch-tuesday-mcp#try-it-instantly--hosted-endpoint-no-install)
with no install at all.
