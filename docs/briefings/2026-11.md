# November 2026 Patch Tuesday Briefing

*Release date: November 10, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The November 2026 security update spans **1,791 entries** in Microsoft's CVRF document
(including Chromium/Edge and open-source components Microsoft redistributes). Of those:

- **86 Critical** and **1,329 Important** severity
- **0 publicly disclosed** before the release
- **4 on the CISA KEV catalog**, and Microsoft itself flags **1 as actively exploited**
  in the wild — [CVE-2026-124194](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-124194),
  an Outlook spoofing bug rated only "Moderate." Severity alone would miss this one.
- Impact mix: Elevation of Privilege (537) leads, followed by Remote Code Execution (298)
  and Information Disclosure (157)

## What to patch first

1. **OpenSSH / musl libc password bypass** — [CVE-2026-123158](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-123158)
   is on the **CISA KEV catalog** with a federal remediation deadline of **November 12** —
   already past due — and carries the **highest EPSS score of the month at 19%**. It affects
   musl-libc Linux systems (Alpine-style) reached via Microsoft's open-source component
   redistribution. Confirm exposure and patch immediately if you haven't.
2. **Outlook Spoofing, actively exploited** — [CVE-2026-124194](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-124194)
   is rated only **Moderate** (CVSS 6.5), but MSRC marks it **Exploitation Detected** and it's
   on the CISA KEV catalog (due **November 24**). Don't let the severity label fool you —
   exploitation status wins.
3. **Edge / Chromium** — [CVE-2026-125350](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-125350)
   (V8/XML use-after-free, sandboxed RCE) is on the CISA KEV catalog, due **November 24**.
   Browser updates are cheap; ship them today.
4. **"Report Deserialization Code Execution"** — [CVE-2026-115731](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-115731),
   Critical severity, on the CISA KEV catalog, due **December 1**.
5. **Windows LDAP RCE** — [CVE-2026-119958](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-119958),
   the highest CVSS score this month at **9.8 Critical**, an unauthenticated RCE in the
   Windows LDAP stack. Fixed by the November cumulative updates (KB5131077 family).
6. **Domain controllers** — [CVE-2026-118146](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-118146)
   (AD DS RCE, Critical 8.8) and [CVE-2026-118148](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-118148)
   (AD DS EoP, Critical 7.5) are both flagged **"Exploitation More Likely"** by Microsoft.
   DCs deserve an early maintenance window this month.

On-prem Exchange admins should also prioritize [CVE-2026-118207](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-118207)
(Exchange Server RCE, Critical 8.8, also "Exploitation More Likely," fixed by KB5133453),
and SharePoint admins have five separate RCEs this month — CVE-2026-109464, -109472, -110044,
-123390, and -124223, all CVSS 8.8, fixed by KB5002945/KB5002908 — worth one combined
maintenance pass rather than five.
