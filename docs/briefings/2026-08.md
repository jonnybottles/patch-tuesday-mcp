# August 2026 Patch Tuesday Briefing

*Release date: August 11, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The August 2026 security update spans **790 entries** in Microsoft's CVRF document
(including Chromium/Edge and open-source components Microsoft redistributes). Of those:

- **108 Critical** and **397 Important** severity
- **2 publicly disclosed** before the release (zero-days by disclosure, neither observed exploited)
- **1 on the CISA KEV catalog**: the Windows Ancillary Function Driver for WinSock elevation-of-privilege flaw [CVE-2026-68820](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-68820), confirmed exploited in the wild, federal remediation due **August 25, 2026**
- Impact mix: Elevation of Privilege (176) leads, followed by Remote Code Execution (111) and Information Disclosure (86)

## What to patch first

1. **Windows AFD for WinSock** — [CVE-2026-68820](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-68820)
   is the only entry on the **CISA KEV** catalog this month, meaning exploitation is confirmed
   in the wild, despite an Important (not Critical) CVSS of 7.0. It touches nearly every
   supported Windows/ESU build (13 KBs across Server 2012 R2 through Windows 11 24H2) — patch this first regardless of severity label.
2. **Windows Deployment Services TFTP Server RCE** — [CVE-2026-62893](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-62893),
   CVSS **9.8 Critical**, flagged by Microsoft as "exploitation more likely." Any WDS server
   with the TFTP role enabled is remotely exploitable pre-auth — a small blast radius but a severe one.
3. **Windows DHCP Server RCE** — [CVE-2026-62823](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-62823),
   CVSS 8.8 Critical, also exploitation-likely. A compromised or malicious client on the
   same segment as a DHCP server is the attack path — prioritize DCs and infra servers running the role.
4. **SharePoint Server RCE** — [CVE-2026-65665](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-65665),
   CVSS 8.8 Critical, exploitation-likely. On-prem SharePoint keeps landing in the
   exploitation-likely bucket month over month; treat it like internet-facing infrastructure even when it isn't.
5. **The two publicly disclosed local issues** — Windows User Profile Service EoP
   [CVE-2026-62832](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-62832) (CVSS 7.8) and Windows
   Container Isolation FS Filter Driver (unionfs.sys) tampering
   [CVE-2026-72971](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-72971) (CVSS 5.5) — neither is
   observed exploited, but assume proof-of-concept code circulates now that details are public. Patch on the normal cycle.

Everything else this month is long-tail: dozens of Critical-severity Azure service
vulnerabilities (Service Bus, Confidential Ledger, SQL Database, Entra Provisioning, SRE
Agent, Purview eDiscovery) that Microsoft remediates server-side with no customer action,
plus the usual open-source/Chromium component set.
