# July 2026 Patch Tuesday Briefing

*Release date: July 14, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The July 2026 security update spans **2,070 entries** in Microsoft's CVRF document
(including Chromium/Edge and open-source components Microsoft redistributes) — one of the
largest releases this year. Of those:

- **118 Critical** and **807 Important** severity
- **1 publicly disclosed** before the release, and **3 confirmed exploited** in the wild
- **4 on the CISA KEV catalog**, all four already past their federal remediation deadlines
  (2026-07-17 through 2026-07-28) — if these aren't patched yet, they're overdue
- Impact mix: Elevation of Privilege (264) leads, followed by Remote Code Execution (176)
  and Information Disclosure (117)

## What to patch first

1. **The on-prem SharePoint chain** — three of this month's four KEV entries are SharePoint
   Server bugs: [CVE-2026-50522](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50522)
   (**Critical 9.8 RCE, 76% EPSS**, KEV due 2026-07-25), [CVE-2026-58644](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-58644)
   (**Critical 9.8 RCE**, confirmed exploited, KEV due 2026-07-19), and
   [CVE-2026-56164](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56164)
   (Moderate EoP, confirmed exploited, KEV due 2026-07-17). Internet-facing on-prem SharePoint
   is this month's single highest-priority target — patch first, then hunt for signs of prior
   compromise (SharePoint Online is not affected).
2. **Active Directory Federation Services EoP** — [CVE-2026-56155](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56155)
   (Important 7.8, confirmed exploited, KEV due 2026-07-28). AD FS sits in front of federated
   identity; treat exploitation here as a precursor to broader account takeover.
3. **Windows DHCP Server RCE** — [CVE-2026-50518](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50518),
   CVSS 9.8 Critical with 11% EPSS — not yet on KEV, but any DHCP server reachable from an
   untrusted network segment is in scope for an unauthenticated RCE.
4. **NGINX Map directive / regex matching flaw** — [CVE-2026-42533](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-42533),
   Critical 8.1, shipped via the Mariner/open-source component channel — check anything running
   Microsoft's redistributed NGINX builds.
5. **BitLocker Security Feature Bypass** — [CVE-2026-50661](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50661),
   the month's one publicly disclosed item. Important severity and local-access only, but assume
   proof-of-concept code circulates — patch on the normal cycle.

Beyond the top five, July is dominated by a long tail of Important-severity Windows kernel and
Win32k elevation-of-privilege fixes (CVE-2026-49798, CVE-2026-49795, and a dozen others) — none
individually urgent, but collectively worth clearing in this cycle's maintenance window since
EoP chains are what turn an initial foothold into full compromise.
