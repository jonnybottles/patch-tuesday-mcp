# July 2026 Patch Tuesday Briefing

*Release date: July 14, 2026 · Generated from the [MSRC Security Update Guide](https://msrc.microsoft.com/update-guide) by [patch-tuesday-mcp](https://github.com/jonnybottles/patch-tuesday-mcp)*

## The month at a glance

The July 2026 security update spans **1,683 entries** in Microsoft's CVRF document
(including Chromium/Edge and open-source components Microsoft redistributes). Of those:

- **117 Critical** and **791 Important** severity
- **1 publicly disclosed** before the release (a BitLocker bypass, not observed exploited)
- **4 on the CISA KEV catalog**, three confirmed exploited in the wild: two SharePoint Server
  RCE flaws — [CVE-2026-50522](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50522)
  (due **July 25**) and [CVE-2026-58644](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-58644)
  (due **July 19**) — plus a SharePoint elevation of privilege
  [CVE-2026-56164](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56164) (due **July 17**)
  and an Active Directory Federation Services elevation of privilege
  [CVE-2026-56155](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56155) (due **July 28**)
- Impact mix: Elevation of Privilege (264) leads, followed by Remote Code Execution (170) and Information Disclosure (113)

## What to patch first

1. **SharePoint Server — three KEV-listed flaws, two confirmed exploited** —
   [CVE-2026-50522](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50522)
   (RCE, **CVSS 9.8 Critical**, **57% EPSS** — the highest in this release) and
   [CVE-2026-58644](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-58644)
   (RCE, CVSS 9.8 Critical, exploited, due **July 19**) are both unauthenticated remote
   code execution. [CVE-2026-56164](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56164)
   (EoP, Moderate 5.3, exploited, due **July 17**) chains with them. On-prem SharePoint keeps
   being a favorite active target — patch today regardless of the CVSS number.
2. **Active Directory Federation Services EoP** —
   [CVE-2026-56155](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-56155)
   (Important, 7.8), confirmed exploited, KEV due **July 28**. Any AD FS servers belong in the
   same emergency change window as SharePoint above.
3. **Windows DHCP Server RCE** — [CVE-2026-50518](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50518),
   CVSS 9.8 Critical, 11% EPSS — the highest EPSS of any entry not on KEV. Unauthenticated
   network RCE against any box running the DHCP Server role.
4. **The Windows kernel / Win32k elevation cluster** — over 20 Important EoP CVEs (CVSS
   6.3–9.3) spanning the kernel, Win32k, DWM, GDI, and CLFS, including
   [CVE-2026-49798](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-49798)
   (CVSS 9.3, the highest of the bunch). All are fixed by the same July cumulative updates —
   one maintenance window covers the lot.
5. **Domain controllers** — with AD FS under confirmed active attack this month, treat identity
   infrastructure broadly as a priority: get the July cumulative onto every DC and federation
   server, not just the AD FS boxes named in CVE-2026-56155.

The remaining publicly disclosed item — BitLocker bypass
[CVE-2026-50661](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50661)
(Important, 6.1, not observed exploited) — is a local issue: patch on the normal cycle, but
assume proof-of-concept code circulates.
